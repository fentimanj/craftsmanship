## Nth Fibonacci

Write a function that generates the Fibonacci number for the

nth position implementing:

int Fibonacci(int position)

First Fibonacci numbers in the sequence are:

| Position | Fibonacci number |
| -------- | ---------------- |
| 0        | 0                |
| 1        | 1                |
| 2        | 1                |
| 3        | 2                |
| 4        | 3                |
| 5        | 5                |
| 6        | 8                |
| 7        | 13               |
| 8        | 21               |
| 9        | 34               |
| 10       | 55               |
