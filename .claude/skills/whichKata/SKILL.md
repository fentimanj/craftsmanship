# whichKata

Read the **Current kata** section of `CLAUDE.md` at the repo root and
state the kata's name and path in one line. For example:

> `Katas/LessonSeven/TicTacToeRefactor`

No elaboration, no status, no next steps — that's what `whereAreWe` and
`whatsNext` are for. If `CLAUDE.md` doesn't clearly name a current kata,
say so plainly rather than guessing.
