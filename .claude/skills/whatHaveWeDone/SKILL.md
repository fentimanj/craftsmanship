# whatHaveWeDone

Give a generous, accurate account of everything covered so far in this
mentoring course — not just the current kata. This is a retrospective
list, not a quiz (`revise`) or a single-kata status report (`whereAreWe`).

## What to do

1. Read the full **Progress log** in `CLAUDE.md` from the start.
2. Read the `Katas/` folder structure to confirm what's actually there —
   lessons and katas the log may not mention explicitly.
3. Present a chronological or lesson-by-lesson list covering:
   - Lessons and katas completed, with a brief note on what each one
     focused on if that's recorded or evident from the code/ReadMe.
   - Major milestones (e.g. the repo reorganisation, a refactor
     completed, a technique newly introduced).
4. Be generous rather than terse — this is meant to give John a real sense
   of progress made, not a bare file listing. But stay accurate: don't
   claim a kata is "done" if the code or log doesn't support it.

## Coaching contract

This is a retrospective summary, not a teaching moment — it's fine to be
straightforwardly informative here, unlike `revise` or `whatsNext`.
